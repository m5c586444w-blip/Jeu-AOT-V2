## Performance (P10.3 ; rendu logiciel SwiftShader, 1366×768 ; bornes basses)
`npm run mesure:r1d -- scenes` (`P10-mesures-r1d.log`, comparé à la fin de R1c) : « mesure:r1d : tous les contrôles passent. »
- Chargement à froid du jeu : **2,72 s** (cible < 8 s ; 3,39 s à la fin de R1c).
- Scène tactique en qualité basse : « prêt » **2,99 s** (< 3 s), corps détaillés 12,9 s, textures 16,3 s.
- Environnements en qualité basse : « prêt » de 2,13 s (murs) à 6,43 s (forêt des Arbres Géants), cible < 8 s.
- Qualités moyenne et haute : « prêt » 5,4 à 30,5 s, corps détaillés jusqu'à 54 s : **GPU réel requis** (dettes n° 1, 49, 64).
- Bataille temps réel, 341 unités, qualité basse (`R2_PARTIES=1 R2_QUALITE=bas npm run smoke:r2`) : « prêt » **4,5 s**, temps JS
  p95 20,1 ms ; au-dessus des 3 s : dette n° 71 (aucune optimisation pour le rendu logiciel, consigne R1e).
- Ticks (`sim:year -- --bench`, `sim:world`) : 845 p95 1,33 ms ; 850 p95 3,56 ms ; 150 provinces 2,46 ms, avec 3 expéditions et
  5 convois 7,63 ms ; 854 **24,16 ms → 5,04 ms** après correction (budget 8 ms ; D-162 ; empreintes inchangées).
- Images par seconde : aucune annoncée (objectif levé en R1c ; mesure sur GPU réel à faire).
