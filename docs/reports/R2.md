## Ce qui est livré
- **R2.1 ordres temps réel** (`src/sim/tactical/realtime.ts`, ajouts à `types.ts`) : `TimedOrder` étendu (unité seule, point, rayon, escouade suivie, formation, file, section visée, objectif et retenue d'un porteur). Ordres déplacer, attaquer (Titan ou section), couvrir, replier, tenir, suivre ; formations ligne, colonne, coin, carré ; file (l'ordre suivant part à l'arrivée) ; tir sur zone, cessez-le-feu, feu à volonté ; ordres généraux des porteurs (l'IA garde la main). Tout passe par le journal (`validTimedOrder` commun à `ResolveBattle` et `ResolveEncounter`).
- **R2.2 compagnies** (`troops.ts`, `setup.ts`) : sections de fusiliers, mitrailleurs, assaut, cavalerie, fusils anti-Titans des deux camps ; tir, mêlée, coups des Titans et de l'artillerie, moral et déroute, IA des sections ennemies ; tirage à part (`trRng`) ; `companySetup` de 100 à 400 unités ; réglages `A` dans `data/balance/tactical.json` (`rt`).
- **R2.3 campagne** : « Livrer bataille » sur une rencontre d'armées ouvre la bataille de compagnies (`encounterSetupRt`) ; l'issue est reportée (`ResolveEncounter` avec `rt: true`, ordres rejoués par la simulation). Chemin ancien inchangé quand `rt` est absent.
- **R2.4 vue 3D** (`src/render/tactical3d/battle/`) : interface `BattleView` (vue 3D three.js chargée à la demande ; adaptateur 2D Pixi `src/render/tactical/view2d.ts`) ; décor dérivé de la carte de la simulation ; un crochet par ancrage ; soldats en trois niveaux de détail, fantassins instanciés, Titans de R1c, canons, impacts, câbles ; violence sobre ou réaliste ; qualités basse, moyenne, haute ; repli 2D avec message sans WebGL 2.
- **R2.5 écran temps réel** (`src/ui/tactical/rtBattleScreen.ts`, logique sans DOM `rtControls.ts`) : clic, Alt + clic (un homme), rectangle, groupes Ctrl + 1–9 / 1–9 ; ordres D A C R T S et formations (F) ; clic droit = ordre par défaut, Maj = file affichée ; pause active (Espace, ouverture en pause) ; tir sur zone au clic (Z), cessez-le-feu (X) ; porteurs ; caméra stratégique ↔ suivi (V) ; carnet, pastilles, sous-titres sans recouvrement ; options vue 3D / 2D, qualité, violence. Branché sur les rencontres d'armées et l'« essai de compagnie » (expéditions).
- **R2.6 contrôle** : `npm run smoke:r2` (captures dans `docs/screenshots/.smoke/`, ignoré par git ; `-- --captures` pour `docs/screenshots/r2-*.png`) ; corrections après revue (D-145) : murs à la hauteur de la simulation, textures des Titans, caméra de suivi sur un homme visible et ligne de vue au-dessus des toits, textes du carnet, étiquette du Titan allié, bilan sans lignes sans objet.
