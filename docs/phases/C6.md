# C6 — Pilier P1 « Le Mur » (spec 26 §2)

**Objectif.** Module pur `src/sim/wall/` : pression démographique, brèche, évacuation, reconquête, désengorgement systémique. Paramètres `[A]` dans `data/balance/wall.json` (schéma `WallBalanceSchema`, `src/data/balance.ts`). Modèle de structure : P3 (`src/sim/gas`) et P4 (`src/sim/signal`).

## Tâches
1. `pressure.ts` : `pression = population / capacité_alimentaire` (district, anneau), niveaux calme/tendu/critique/rupture, pas quotidien (naissances, décès, épidémies, ordre, rations), flux de réfugiés conservatifs, compteur de mois, pression perçue (brouillard).
2. `breach.ts` : seuil de brèche sur `wall_structure` (même sens que `siege.breached`, `armies.ts:~1225`), évacuation horaire (porte d'accueil, débit, marche, pertes par heure de retard), portes (coût politique), abandon, reconquête progressive.
3. `decongest.ts` : décision à trois branches (rationner / désengorger / nouvelles terres), effets politiques drainables, aléa injecté.
4. `strategic.ts` : pont depuis `ProvinceState` (économie). N'utilise pas `armies.pressure` (occupation, autre concept, C0-audit B8).
5. Tests `tests/sim/wall/*.test.ts`.

## Critères d'acceptation
- `npm run typecheck && npm run lint` verts.
- `npx vitest run tests/sim/wall` : déterminisme, monotonie de la pression, conservation (`conservationGap ≈ 0`), effets d'une évacuation, scénario « Maria tombe → Rose critique < 12 mois + décision proposée », absence de fuite de pression exacte.
- `npm run data:validate` liste `wall`.
- `npm run verify` vert ; aucune empreinte de référence modifiée (module non branché au tick).

## Hors périmètre
Branchement au tick, aux alertes et à `economy.ts` ; écran « Mur » (UI) ; `npm run sim:year` ; événements E04–E06 ; propagation en réseau (siège `owner` conservé mais non exploité) ; calibrage des capacités réelles par province (table `layout` fournie par l'appelant).
