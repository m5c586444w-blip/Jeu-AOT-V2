# C8 — Piliers P6 « La Vérité » puis P7 « Le Registre » (spec 26 §7, §8)

**Objectif.** P6 : modules purs `src/sim/truth/` (fiabilité A–D par fait et par faction, dossier de preuves, actes, attracteurs de canon). P7 : `src/sim/register/` (registre des morts, troupe nommée ≈ 50–80 + générée tracée). Paramètres `[A]` dans `data/balance/truth.json` puis `register.json` (schémas Zod dans `src/data/balance.ts`). Modèle de structure : `src/sim/clock`, `src/sim/tide`.

## Tâches
**P6 (étape 1, faite en premier)**
1. `dossier.ts` : faits (véracité réelle) ; pièces par faction (source, affirmation, origine, qualité) ; fiabilité A–D (poids de source, vieillissement, corroboration d'origines indépendantes, contradictions) ; découverte (`reveal`) ; conséquence d'une erreur (`decide`) ; coût mental des visions.
2. `acts.ts` : trois actes par faction, débloqués par la **connaissance vraie** de faits (jamais par menu) ; capacités (mer, ports, marine, aviation réservées) ; acte de départ par scénario (845/850/854).
3. `attractors.ts` : proximité aux conditions de l'histoire, écart cumulé, attraction décroissante avec la divergence, bascule de branche ; attracteurs de faction lus dans `data/factions`. Réutilise `events/engine.ts` (`ready`, `schedule` exportés, comportement inchangé).
4. `view.ts` : dossier par faction et par siège (jamais la véracité d'un fait non vérifié, jamais le dossier d'autrui).
**P7 (étape 2)** : dossier de mort pour chaque soldat, nommés/générés/promotion, relations → moral/stress, registre et stèle, effet sur opinion et recrutement.

## Critères d'acceptation
- `npm run typecheck && npm run lint && npm run data:validate` verts ; `truth` listé.
- `npx vitest run tests/sim/truth` : aucune donnée morte (proxy), levier de chaque paramètre, anti-fuite (véracité, autre faction, siège), invariant « aucun fait sûr sans source », canon qui se déclenche / diverge, déterminisme, entrées non mutées.
- `npm run verify` vert ; aucune empreinte modifiée tant que le module n'est pas branché au tick.

## Hors périmètre
Branchement au tick et aux commandes, écran Dossiers / Registre, génération des pièces par les systèmes (espions, archives, Chemins), événements scénarisés d'actes, réseau.
