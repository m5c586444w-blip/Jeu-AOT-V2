Séquencé par la session A (B n'a pas travaillé ; D-182). Tranche 1 = outillage + accessoires ; tranche 2 = tenues.

## Tranche 1 (cette nuit)
1. `tools/blender/` : `common.py` (scène vide, matériaux nommés, application d'échelle, axe Y haut, mètre, origine aux pieds, comptage de triangles, export glb déterministe), un script par famille (`armes.py` : lame ODM, lance de foudre ; `armes_a_feu.py` : fusil, canon + chariot-canon ; `odm.py` : dispositif ODM ; `tenues.py` plus tard).
2. `npm run assets:blender` : crée `.venv-blender` + `pip install bpy` si absent, relance les scripts, écrit `docs/art/assets/projet/*.glb` et met à jour les entrées du manifeste (`origine: "creation-projet"`, script, sha256), échoue si l'empreinte d'un glb ne correspond plus à une régénération (déterminisme) — sinon, documenter.
3. `assets:check` (src/tools/assetsCheck.ts) accepte `origine: "creation-projet"` (exige script existant + empreinte + licence CC0 création originale), refuse toujours les sources tierces non retenues ; tests.
4. `tests/art/models.test.ts` : budget triangles (accessoire ≤ 1 500), hauteur/longueur réelle plausible, ≤ 4 matériaux, matériaux nommés, origine aux pieds/poignée. Lit les glb (parse JSON glTF, pas de three).
5. `docs/ASSETS_LICENSES.md` : section « Créations du projet ».

## Critères
