# Phase P10 — finitions, accessibilité, documentation

Sources : fichier 18 §10 (prompt), 05 §5, 09 §20 (accessibilité F-ACC-01 à 08), 04 §9 (latence : chargement < 8 s à froid, scène
tactique < 3 s), 15 (CONFORMITE.md), 23 §6 (PACK, phase suivante). Départ : commit de fin de P9. Branche
`claude/intelligent-feynman-8ekib4` (D-148). Plafond : 120 tours. Pas d'arrêt de revue (ROADMAP) ; arrêts obligatoires 1 à 4.
`src/sim` : seulement ce qu'exige une tâche (difficultés fines), ajouts déterministes, couches facultatives (absentes : hash
inchangé). Aucune publication en ligne (usage personnel).

## Tâches
- **P10.1 Accessibilité (09 §20)** : existant vérifié (taille de l'interface 100–200 %, contrastes AA testés, sous-titres,
  clavier complet, pause et vitesses) ; ajouts : mode daltonien (couleurs de nations et d'alertes distinguables sans le rouge
  et le vert), réduction des mouvements et des flashs (animations, secousses de caméra, éclairs), aide à la lecture (polices
  décoratives remplacées, interlignage et espacement accrus — aucune police nouvelle : CLAUDE.md), difficulté personnalisée
  (production, Titans, IA, pertes réglables au menu, gardée dans la sauvegarde).
- **P10.2 Parcours complet** : un script joue cinq ans du scénario 850 par commandes enregistrées ; à chaque année :
  sauvegarde, chargement, migration (version) vérifiés, même empreinte qu'en continu ; aucun blocage.
- **P10.3 Performance** : latences de 04 §9 mesurées au rendu logiciel (chargement à froid, scène tactique « prête ») ; tick de
  simulation par scénario ; « GPU réel requis » pour le reste ; jamais d'images par seconde annoncées sans mesure.
- **P10.4 Documentation** : README (installation et lancement en local, scripts à jour), manuel en jeu (registre « Manuel »
  ou page d'aide), DECISIONS.md final (index), CANON_CHECK.md final, ASSETS_LICENSES.md vérifié, `docs/CONFORMITE.md` rempli
  par section normative (FAIT / PARTIEL / ABSENT justifié).
- **P10.5 Lancement local** : build statique (`npm run build`) et instructions pour jouer sur un ordinateur sans réseau
  (`npm run preview` ou fichier de lancement) ; rien n'est publié.
- **P10.6 Audit canon** : dernière passe `canon:check` ; aucun fait de lore sans statut C/A/? ; trois listes (sourcé,
  interprété, non confirmé) dans le rapport.
- **P10.7 Fin de phase** : tous les `smoke:*` lancés (échecs expliqués ou corrigés), captures, `docs/reports/P10.md`
  (≤ 150 lignes), PROGRESS, ROADMAP.
