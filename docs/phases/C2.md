# C2 — Lore créé et emblèmes (ERRATA_V3 §2)

## Tâches
1. `data/emblems/emblems.json` : 12 emblèmes (4 nations, 8 organisations) comme objets de données (champ, couleurs, charges tracées), tous `canon: "A"`, `creation: true`, raison.
2. `src/data/emblemSchemas.ts` (Zod strict, tracé limité à un jeu de caractères sûr, identifiant = `emb_<sujet>`), `src/data/emblemSvg.ts` (rendu trait `currentColor` pour l'interface ; rendu couleurs avec découpe par le champ pour texture/décalque).
3. `emblem()` de `src/ui/icons.ts` lit les données (plus de tracés en dur). Pastille pointillée en mode auteur (`data-canon="A"`).
4. `data:validate` valide le fichier ; `canon:check` règle R15 (création = A + raison + inscrite dans `docs/lore/creations.md`, jamais C).
5. `docs/lore/creations.md` : une ligne par emblème. Noms traduits `emb.name.*`.

## Critères d'acceptation
- `npx vitest run tests/data/emblems.test.ts` vert ; `npm run canon:check` conforme ; un fixture `canon: "C"` + `creation: true` est rejeté (R15).
- `npm run verify` code 0. Planche `docs/screenshots/c2-emblemes.png` relue (3 lignes, ≥ 3 défauts).

## Hors périmètre
Décalque 3D posé sur les modèles Blender (C10/C11) ; texture rastérisée (même SVG, au moment de C10) ; création de noms de personnages et de lieux (C15 à C18).
